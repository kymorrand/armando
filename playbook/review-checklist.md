# Post-Dispatch Review Checklist

After every Bloom, Root, or Canopy dispatch:

1. [ ] Did they write tests for new code?
2. [ ] Do existing tests pass?
3. [ ] Does lint pass?
4. [ ] Did they stay within their file scope per CLAUDE.md?
5. [ ] Does the code follow project conventions?
6. [ ] Are there new dependencies not accounted for?
7. [ ] Is CHANGELOG.md updated?
8. [ ] No hardcoded IPs, credentials, or secrets?
9. [ ] Error handling on all external calls?
10. [ ] Update Linear issue status based on findings
