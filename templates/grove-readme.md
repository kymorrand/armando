# _grove — Project Vault

This is the project-specific documentation vault, maintained by Armando.

## Structure

```
_grove/
├── reports/    # Development reports, garden reports, session summaries
├── adrs/       # Architecture Decision Records
├── sprints/    # Sprint plans and retrospectives
├── designs/    # Design docs, technical specs, component designs
└── README.md   # This file
```

## Conventions

- **Reports** are named `{type}-{date}.md` (e.g., `garden-2026-03-24.md`)
- **ADRs** are numbered `adr-{NNN}-{slug}.md` (e.g., `adr-001-git-lfs.md`)
- **Sprint plans** are named `sprint-{N}-{slug}.md`
- **Design docs** are named `design-{slug}.md`
